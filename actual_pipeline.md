L'idee initiale : ResNet-18 3D comme extracteur de features images (512 dims), combiné avec un MLP clinique (32 dims), le tout fusionné par un MLP de fusion (544 → 128 dims), avec une risk head pour les losses (DeepHitLoss + ContrastiveLoss), et au final un BaggedIcareSurvival (librairie icare) entraîné sur les features 128 dims pour la prédiction finale.

En 2025 : Les gagnants 2025 (équipe SIMS-LIFE) ont utilisé une version modifiée de DeepMTS : un 3D U-Net (blocs résiduels) comme backbone de segmentation qui reçoit CT+PET concaténés et produit à la fois le masque de segmentation et 124 deep features (z₁), puis un 3D DenseNet (blocs denses) comme backbone de classification HPV qui reçoit CT+PET + la carte de probabilité tumorale et produit la prédiction HPV et 112 deep features (z₂). Les features z₁ (124 dims) + z₂ (112 dims) + features cliniques (7 dims) sont concaténées et passées dans une branche de survie (3 couches FC) qui prédit le score de risque. Le tout est entraîné end-to-end avec une loss multitâche : Dice+Focal (segmentation) + Focal cross-entropy (classification HPV) + Cox negative log partial likelihood (survie) + 0.1×L2 regularization.

Ma proposition pour 2026 : Un framework multitâche end-to-end à quatre branches, construit autour d'un SwinUNETR (MONAI) comme backbone de segmentation qui reçoit CT+PET concaténés et produit le masque de segmentation + des deep features d'encodeur (z₁), puis un ViT 3D pré-entraîné avec les poids 3DINO (projet externe AICONSlab, non natif MONAI) comme backbone de classification qui reçoit CT+PET + la carte de probabilité tumorale du SwinUNETR et produit trois prédictions — HPV, T-stage, N-stage — ainsi que des deep features (z₂). Les features cliniques brutes (7 dims) sont d'abord enrichies par un petit MLP (7 → 64 → 32) pour produire un vecteur de représentation clinique plus expressif. Contrairement aux approches précédentes qui concatènent simplement les features, les vecteurs z₁, z₂, les logits T/N staging et le vecteur clinique enrichi sont fusionnés via un module de cross-attention où chaque modalité constitue un token, permettant au réseau d'apprendre dynamiquement les interactions entre features d'imagerie, staging et données cliniques. La sortie du token CLS alimente une branche de survie (couches FC) qui prédit le score de risque RFS. Le tout est entraîné end-to-end avec une loss multitâche : Dice+Focal (segmentation) + Focal cross-entropy (classification HPV) + CrossEntropy (T-stage) + CrossEntropy (N-stage) + Cox negative log partial likelihood (survie) + L2 regularization. Les gradients de la loss de survie remontent à travers le module de cross-attention jusqu'aux backbones de segmentation et de classification, forçant les deux encodeurs à produire des features non seulement utiles pour leurs tâches respectives, mais aussi informatives pour le pronostic.
